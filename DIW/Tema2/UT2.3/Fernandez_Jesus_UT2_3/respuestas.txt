    # Menú principal:
    <div class="menu"> → <nav class="menu" aria-label="Navegación principal">

    # Contenido principal:
    <div class="contenido"> → <main>

    # Título:
    <div class="titulo">Fotografía con móvil</div> → <h1>Fotografía con móvil</h1>

## Preguntas punto 3:

# A. ¿Por qué un div no explica por sí mismo que contiene el menú?

Un div es un contenedor genérico y no indica qué función tiene su contenido. El elemento nav sí tiene un significado semántico que indica que contiene una zona de navegación.

# B. ¿Qué diferencia hay entre title y h1 en esta página?

El elemento title indica el título de la página en el navegador y en otros contextos, mientras que h1 es el encabezado principal que forma parte del contenido visible de la página. En este caso, title contiene "AulaActiva | Fotografía" y h1 contiene "Fotografía con móvil".

# C. ¿Qué relación hay entre for e id? ¿Para qué sirve name?

El atributo for del label debe coincidir con el id del campo al que pertenece. Así se establece la asociación entre la etiqueta y el control. El atributo name identifica el dato que se enviará cuando se envía el formulario.

# D. ¿Puede CSS arreglar por sí solo un enlace cuyo destino no existe?

No. CSS solo modifica la presentación visual. Para corregir un enlace cuyo destino no existe hay que modificar el HTML, haciendo que href coincida con el id de la sección de destino.

# E. ¿Un formulario válido confirma una inscripción real? Explica la respuesta.

No. El formulario de esta actividad solo sirve como demostración. La validación comprueba que los datos introducidos cumplen determinadas condiciones, pero no significa que exista una inscripción real. Además, el formulario utiliza method="get" y no está conectado a un sistema que gestione reservas.
