* En solicitud.html aparece <imput type="radio"...>. El elemento correcto es <input type="radio"...>.

PREGUNTAS DE REVISIÓN

1. Copia un campo de tu formulario y explica para qué sirven id, name y for.

Campo utilizado:

<input type="email" id="email" name="email" required autocomplete="email" />

* id="email": identifica de forma única el campo dentro de la página y permite relacionarlo con su etiqueta.
* name="email": indica el nombre del dato que se enviará cuando se envíe el formulario.
* for="email": se utiliza en la etiqueta label para relacionarla con el campo que tiene ese mismo id.

En este caso:

<label for="email">Correo electrónico *</label>

El atributo for="email" hace referencia al id="email" del campo.

2. ¿Por qué los radio del turno tienen el mismo name?

Los dos botones de opción del turno tienen el mismo atributo name="turno" porque pertenecen al mismo grupo de opciones.

De esta manera, solamente se puede seleccionar una de las dos opciones: "Mañana" o "Tarde".

Si cada botón tuviera un name diferente, podrían seleccionarse los dos al mismo tiempo.

3. Escribe tres pares nombre=valor observados en un envío válido.

Tres ejemplos de pares nombre=valor que se pueden observar en un envío válido son:

nombre=Juan%20Pérez
email=[juan@gmail.com](mailto:juan@gmail.com)
actividad=fotografia

También se pueden enviar otros datos, como:

plazas=2
turno=mañana
recordatorio=si

4. ¿Qué ocurre con el dato de recordatorio cuando no marcas la casilla?

Cuando la casilla de recordatorio no está marcada, no se envía ningún dato para ese campo.

Cuando sí está marcada, se envía:

recordatorio=si

Por tanto, si no se marca la casilla, recordatorio=si no aparece en los datos enviados.

5. ¿Se ha guardado una reserva real? Explica qué faltaría.

No, no se ha guardado una reserva real.

El formulario utiliza method="get", por lo que los datos se envían mediante la URL. Actualmente solamente se está comprobando el funcionamiento del formulario.

Para guardar una reserva real sería necesario disponer de un servidor que recibiera los datos, los procesara y los almacenara, por ejemplo, en una base de datos.

También sería necesario indicar mediante el atributo action la dirección del servidor que recibiría los datos.

6. Copia un alt de tu proyecto y justifica qué información aporta.

Ejemplo:

alt="Fotografía"

Este texto proporciona una descripción de la imagen. Es útil para las personas que utilizan lectores de pantalla y también en caso de que la imagen no pueda cargarse.

En este caso, "Fotografía" permite conocer de forma sencilla qué representa la imagen.
