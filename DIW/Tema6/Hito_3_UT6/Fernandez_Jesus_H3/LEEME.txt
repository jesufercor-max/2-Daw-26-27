MÉTODO UTILIZADO PARA TAILWIND
  Tailwind CSS v4 COMPILADO (no se usa el script Browser, así que no hay carpeta vendor/).
  - HTML con utilidades: tailwind/index.html y tailwind/detalle.html
  - Entrada y configuración (paleta, tipografía, puntos de ruptura 600 y 900 px): tailwind/src/input.css
  - Resultado que cargan las páginas: tailwind/css/tailwind.css
  - Dependencias declaradas: tailwind/package.json (opcional) y tailwind/compilar.sh
  Orden para regenerar el CSS (sin root; descarga el ejecutable de Tailwind en tailwind/bin/):
      cd tailwind
      bash compilar.sh
  (equivale a: tailwindcss -i ./src/input.css -o ./css/tailwind.css --minify)
  Alternativa con Node: npm install && npm run build. Se ha borrado tailwind/bin/ antes de entregar.
  Licencia: tailwind.css conserva en su primera línea el aviso "MIT License" de Tailwind CSS.
  CSS propio: una sola excepción documentada en src/input.css (anillo de foco común con @apply).
