1. CLIENTE Y SERVIDOR
- Cliente: navegador; interpreta HTML, CSS y JavaScript.
- Servidor: recibe solicitudes HTTP, ejecuta PHP y devuelve HTML o datos.
- Web estática: devuelve contenido fijo. Web dinámica: genera respuestas según datos/usuario.
- HTTP: GET solicita recursos o envía parámetros en la URL; POST envía datos en el cuerpo.
- Componentes habituales: Apache (servidor), PHP (lógica), MySQL (base de datos), XAMPP (paquete).
- Una aplicación web funciona en un servidor y se usa desde el navegador.

2. PRIMER PHP DENTRO DE HTML
<!doctype html><html><body><?php echo "Hola mundo"; ?></body></html>
- Guardar como .php y abrir desde localhost con PHP/Apache iniciado; no abrir con doble clic.
- <?php ... ?> delimita PHP; cada instrucción suele acabar en ;
- echo imprime texto/HTML; concatenar cadenas con punto: echo "Hola ".$nombre;
- Comentarios: // línea, # línea, /* varias líneas */.

- Constantes: define("PI", 3.14); o const PI = 3.14;
- Operadores: + suma; - resta; * producto; / división; % resto; ** potencia.
- ++ aumenta 1, -- disminuye 1, .= concatena acumulando.
- Comparaciones: == mismo valor, === mismo valor y tipo, != distinto, < > <= >=.
- Lógicos: && (Y), || (O), ! (NO).
- Funciones: rand(1,100), round($n,2), floor($n), ceil($n), abs($n), sqrt($n).
- Diagnóstico: var_dump($dato), print_r($array), isset($dato).

9. NÚMEROS PRIMOS (TEMA IMPORTANTE)
Un número primo es un entero MAYOR QUE 1 con exactamente dos divisores positivos:
1 y él mismo. 0 y 1 NO son primos; 2 sí es primo (el único primo par).
El operador % devuelve el RESTO de la división.
Ejemplo: 10 % 2 = 0 (10 divisible por 2); 11 % 2 = 1.

A) COMPROBAR SI UN NÚMERO ES PRIMO:
<?php
function esPrimo($n) {
    if ($n < 2) return false;
    for ($i = 2; $i * $i <= $n; $i++) {
        if ($n % $i == 0) return false;
    }
    return true;
}
$numero = 17;
echo esPrimo($numero) ? "Es primo" : "No es primo";
?>
Explicación: probamos posibles divisores desde 2 hasta la raíz cuadrada.
Si alguno divide sin resto, el número NO es primo.

B) MOSTRAR TODOS LOS PRIMOS ENTRE 1 Y N:
<?php
$n = 100;
for ($numero = 2; $numero <= $n; $numero++) {
    if (esPrimo($numero)) echo $numero . " ";
}
?>
Ejemplo hasta 20: 2 3 5 7 11 13 17 19.

C) SACAR LOS FACTORES PRIMOS DE UN NÚMERO (DESCOMPOSICIÓN):
<?php
$n = 60;
$restante = $n;
$factores = [];
for ($divisor = 2; $divisor * $divisor <= $restante; $divisor++) {
    while ($restante % $divisor == 0) {
        $factores[] = $divisor;
        $restante /= $divisor;
    }
}
if ($restante > 1) $factores[] = $restante;
echo implode(' x ', $factores);
?>
Resultado de 60: 2 x 2 x 3 x 5.
Diferencia: «primos hasta N» lista primos menores/iguales a N;
«factores primos de N» busca los primos que multiplicados forman N.

10. CADENAS Y FECHAS (MENCIONADAS EN EL TEMARIO)
- strlen($texto): longitud en bytes; mb_strlen($texto): caracteres Unicode.
- strtoupper / strtolower: mayúsculas / minúsculas (para acentos, mb_*).
- substr($texto,0,3): subcadena; str_replace('a','b',$texto): sustituir.
- strpos($texto,'a'): posición o false si no aparece.
- date('Y-m-d'): fecha actual; time(): marca de tiempo; strtotime(): interpretar fechas.

11. SESIONES Y COOKIES (MENCIONADAS EN EL ÍNDICE)
- session_start() inicia/reanuda sesión ANTES de imprimir HTML.
- $_SESSION['usuario'] = 'Ana'; guarda información entre peticiones.
- unset($_SESSION['usuario']); elimina dato; session_destroy(); destruye sesión.
- setcookie('tema','oscuro',time()+3600); configura cookie antes de imprimir HTML.
- $_COOKIE['tema'] lee una cookie en peticiones posteriores.
